Acerca de GeneMovie

GeneMovie es un proyecto privado de Android para descubrir películas y series mediante títulos, sinopsis, fechas de estreno, puntuaciones e imágenes.

La aplicación utiliza metadatos de The Movie Database (TMDB) para facilitar la exploración de contenido audiovisual.

Esta página presenta el proyecto y no ofrece reproducción directa de películas.
